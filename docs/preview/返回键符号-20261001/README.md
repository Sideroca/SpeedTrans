# 译文面板 · 返回键（方向键）符号微调 · 2026-10-01

## 需求（轻响原话）
> 方向键符号**缩小 10%**，但**按钮判定范围不要缩小**；符号看起来**更浅一些**，尽量不引人注意。

## 改法（`ResultOverlay.ensure()`）
| 项 | 改前 | 改后 | 说明 |
|---|---|---|---|
| 符号本体 | 32dp | **28.8dp**（−10%） | 靠**内距**收缩：`setPadding(6dp) → dpf(7.6dp)` |
| 判定范围 | 44×131dp | **44×131dp（未动）** | 是 ImageView 的 layoutParams，内距不影响点击区 |
| 透明度 | alpha 0.62 | **alpha 0.45** | 只降透明度（不动素材），对任何面板底色都是"更浅" |

**符号宽度算法**：`44dp − 2×6dp = 32dp` → 缩 10% = `28.8dp` → 内距 `(44−28.8)/2 = 7.6dp`。

> 注：源码注释原写"箭头本体 ≈32dp"略夸——素材 `ic_back_arrow.png` 299×193、图形 bbox 273×166（自带 13px 边距），
> 按 FIT_CENTER 落进 32dp 盒子后**可见图形实际 ≈29.2dp**。上面的 32dp 指的是绘制盒宽（注释口径）。

# ⚡ 闪译 SpeedTrans

**点一下悬浮球，当前屏幕文字立即流式翻译成中文。**
安卓悬浮球流式翻译工具：无障碍取词 → LLM 流式中译 → 悬浮面板实时上屏，首字 1~2 秒。

![全部主题](docs/preview/all.png)

## 🎯 软件目标（设计哲学）

**① 极速** —— 整个流程为快而生，能做的不只是翻译。
首字 1~2 秒是生命线：秒回（内容未变 0 请求）、增量翻译（只译新增段）、默认最快思考档——每一处交互都为"快"让路。

**② 兼容性和稳定性** —— 少 bug，可以在多个手机系统上使用。
全部基于标准 Android API（无厂商 / 谷歌依赖）；小米 / vivo / OPPO / 荣耀等 ROM 的保活、权限、受限设置差异逐条适配——宁可多一步图文引导，不留一个闪退。

**③ 自定义程度** —— 给用户充足的自定义空间和权限，让他们能够选择自己想要的。
64 套主题（18 现代 + 46 中国传统色）、45 色釉色库、悬浮球形状 / 大小 / 颜色 / 图片（含内置「吐魂」球）、面板高度与按钮、接口 / 模型 / 参数全开放、译文累积开关……凡是有分歧的地方，尽量做成选项，而不是替用户决定。

**底线**：任何新加的功能不应该削弱现有的功能，至少不能是大幅削弱。遇到取舍冲突，先讨论，再动手。

## ✨ 功能一览

### 翻译核心
- **两态模式**：📄 仅文本（无障碍取词，原文零误差）/ 🖼 仅识图（静默截屏 + ML Kit 端侧识别，全屏 100% 内容），通知栏点一下即切
- **流式输出**：OpenAI 兼容 SSE，首字 1~2 秒；增量翻译（模型思考类持续增长内容只译新增段）；相同内容 0 请求秒回
- **长按选取**：译文长按进入系统选择，复制指定内容；「复制」按钮复制全文
- **翻译历史**：最近 200 条纯本地回溯（增量翻译自动合并），点卡片复制全文

### 智能接口（44 色库联动）
- **六家预设**：千问 / DeepSeek / 豆包 / GLM / Kimi / ChatGPT，服务商候选包含式联想（浏览器式），选中自动填地址 + 模型名
- **模型联想**：输入任意片段（如 `v4`）即命中全库模型名
- **思考档位**：关 / 低 / 高 按服务商自动换算成各家参数（`enable_thinking` / `thinking.type` / `reasoning_effort`），默认最快档
- **钥匙按服务商归档**：切换服务商只出现「🔑 点此填入」提示，**点了才填**（不在屏幕上自动亮出密钥）
- **测试连接电路动画**：💡 + 开关闭合 + 绿色电流从正极缓缓填满导流槽（ing / 200 / 404）

### 悬浮球与面板
- **悬浮球**：文字球 / 图片球（相册选图或内置「吐魂」），圆形 / 圆角方形 / 切角八边形 / 三角形 / 长方形（竖）五种形状，大小三档
- **译文面板**：文字大小 12~24sp 实时可调、面板高度、按钮大小与位置、撞色条独立选色（45 色釉色库，**浅空蓝打头**，纯平色渲染，默认影青）、译文累积（面板不关时新译文追加在下方）
- **长按选取复制**、复制全文双轨

### 个性化
- **设置页皮肤**：炫酷黑（扫描线 + 光束 + 切角）/ 跟随主界面主题（64 套配色穿控制台骨架）
- **主题系统**：46 套中国传统色主题（每个配色含浅/深版式、古典搭配与对比度保底）+ 18 套现代经典；默认「茶文化 · 竹青」
- **页面壁纸**：设置页 + 主界面装饰底层，零交互，遮罩浓度可调
- **快捷图标工坊**：网格轨道球 / 双轨道环两种样式（均按定稿图 1:1 矢量描摹）× 45 色自由配色，实时预览，一键钉到桌面
- **还原成默认图标**：一键把桌面图标复位为默认（旧的伪装循环已移除）
- **彩蛋**：🏒 霓虹空气曲棍球（设置 → 其他；原生移植自 Matt Cannon 的 Air Hockey，MIT）

### 火焰细节
- **火把光标**：输入框光标 = 小火把（火苗 + 木杆），与输入法无关
- **火焰删除**：删除字符原地引燃（金黄→橙→深红，上飘摇曳 + 火星）
- **灯泡余烬**：测试成功闪光喷出白 / 黄 / 绿余烬

### 隐私与安全
- 钥匙、历史、壁纸全部**只存本机**；OCR 端侧识别不上传；零存储权限、零通讯录权限
- **零内置密钥**：全新安装 = 未配置，一切密钥由你自己填、只存本机；已关闭云备份与换机迁移（配置不会随设备走）
- 通知图标：点阵双环白描（纯剪影，系统染色）

## 🚀 快速开始

1. 下载安装（Release 或 Actions 产物）
2. 授予悬浮窗权限 + 开启无障碍服务（MIUI 会弹「危险」确认，放心允许）
3. 首次使用：设置 → 🔌 接口 → 点选服务商（自动填地址 / 模型名）→ 粘贴你自己的 API Key → 保存
4. 点球即用，日常无需打开本应用

### MIUI 防杀后台（一次性）
1. 最近任务长按本应用卡片 → 🔒 锁定
2. 应用详情 → 省电策略 → 无限制
3. 应用详情 → 自启动 → 开启

### ⚠️ 安装方式与「受限设置」
Android 13+ 通过微信 / QQ 等会话式安装器安装的 APK，无障碍开关会被系统置灰。
**请用系统自带文件管理器安装**，或：应用详情 → 右上角 ⋮ → 允许受限制的设置。

## 🏗️ 构建（GitHub Actions 云端出 APK，无需电脑）

1. push 即触发构建（或 Actions → Build APK → Run workflow）
2. 等 3~5 分钟 → 该次运行 → Artifacts → 下载 `SpeedTrans-debug-apk`

## 🧭 架构速览

```
BallService(无障碍: 悬浮球/取词/截屏) ─┬─ TextCollector(节点树→文本+坐标)
                                      ├─ OcrEngine(ML Kit 五语言并行+跨识别器去重)
                                      └─ KeepAliveService(前台保活+通知控制中心)
TranslateCoordinator(单例总线: 两态分发/增量/秒回/忙碌忽略)
  ├─ TranslateEngine(流式SSE; 44色库服务商预设; 思考档位参数映射)
  └─ ResultOverlay(译文面板: 撞色条/捕捉层/长按选取)
ThemeEngine(22套配色) + ShellSkins(设置页皮肤) + SettingsStore(单一事实源)
IconStudio(快捷图标工坊) + HistoryStore(本地历史)
```

- 无第三方 SDK 依赖（仅 OkHttp + AppCompat + ML Kit）；全标准 API，vivo / OPPO / 荣耀可用
- ABI 拆分 arm64-only；签名固定（debug.keystore 入库，所有版本可互相覆盖安装）
